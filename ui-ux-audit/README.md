# نظام فحص تجربة الاستخدام (UI/UX Audit)

نظام فحص محلي ومستقل عن الموقع. يقرأ نسخة الإنتاج من `../app` ولا يعدّل أي ملف فيها. كل الأدوات مفتوحة المصدر وتعمل على الجهاز نفسه.

## ابدأ من هنا
- **لوحة النتائج:** افتح `dashboard/index.html` في المتصفح مباشرة.
- **الملخص:** `reports/EXECUTIVE-SUMMARY.md`.
- **المشاكل:** `reports/BUGS-AND-ISSUES.md` (29 مشكلة بالدليل والحل وحالة كل واحدة).
- **ما تم إصلاحه:** `reports/FIXES-AND-RESULTS.md` (نفس الفحوص قبل وبعد).

## المجلدات

| المجلد | المحتوى |
|---|---|
| `reports/` | التقارير العشرة بالعربية، وتقرير الإصلاحات |
| `pages-inventory.md` | جرد الصفحات العشر وحالاتها الـ38 |
| `dashboard/` | لوحة النتائج، تعمل بلا إنترنت |
| `screenshots/` | لقطات لكل حالة على 5 مقاسات (`m360`، `m390`، `t768`، `d1366`، `d1920`)، وصفحات كاملة (`full/`)، ولوحات مجمعة (`contact-*.jpg`)، وأدلة المشاكل (`evidence/`) |
| `personas/` | سكربت الشخصيات الست ولقطات كل خطوة |
| `results/` | نتائج JSON لكل أداة، وتقارير Lighthouse وUnlighthouse الكاملة (HTML) |
| `tests/` | سكربتات الفحص |
| `config/` | إعدادات pa11y وUnlighthouse |
| `logs/` | سجلات التشغيل ولقطات الاختبارات الفاشلة |

## الأدوات (بإصدارات مثبتة)

| الأداة | الإصدار | الرخصة | الاستخدام |
|---|---|---|---|
| Playwright | 1.63.0 | Apache-2.0 | التحكم في المتصفح، واللقطات، والاختبار الوظيفي، والشخصيات |
| axe-core و@axe-core/playwright | 4.14 | MPL-2.0 | إمكانية الوصول لكل حالة |
| pa11y و pa11y-ci | 10.0 و5.0 | LGPL-3.0 | إمكانية الوصول (HTML_CodeSniffer + axe) |
| Lighthouse | 13.6.0 | Apache-2.0 | الأداء والوصول وSEO |
| Unlighthouse | 0.19.1 | MIT | فحص كل الصفحات دفعة واحدة |

- **المتصفح:** Chromium الموجود على الجهاز. لم يُنزَّل متصفح إضافي.
- **حجم الأدوات:** حوالي 600 MB في `node_modules`، وهي غير مرفوعة على GitHub.

## إعادة الفحص بعد أي تعديل
```bash
cd ui-ux-audit
npm install                 # أول مرة فقط
npm run serve               # في نافذة: يشغّل نسخة الإنتاج من ../app على المنفذ 4173
npm run audit:all           # في نافذة أخرى: كل الفحوص ثم التقارير ولوحة النتائج
python3 tests/compare.py    # المقارنة مع results/before
```

لو غيّرت المسار، فالموقع لازم يكون مبني أولاً (`npm run build` داخل `app`).

## حدود الفحص
- **الشخصيات محاكاة آلية:** تحتاج تأكيداً باختبار على مستخدمين حقيقيين.
- **لم يُختبر:** Safari وiPhone، وقارئات الشاشة الفعلية، والشبكات الحقيقية.
- **لم يُستخدم Ollama:** الجهاز بلا كارت شاشة، والنماذج المحلية على المعالج بطيئة وضعيفة في الحكم على التصميم.
