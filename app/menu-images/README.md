# صور الأصناف

ضع هنا صورة كل صنف، والتطبيق يربطها بالصنف تلقائياً من **اسم الملف**. لا تحتاج تعديل أي ملف بيانات.

## القاعدة
اسم الملف = اسم الصنف كما يظهر في المنيو، ثم الامتداد.

| الصنف في المنيو | اسم الملف |
|---|---|
| صدور فراخ | `صدور فراخ.jpg` |
| كفتة فراخ | `كفتة فراخ.jpg` |

- الامتدادات المقبولة: `jpg` و`jpeg` و`png` و`webp`.
- المطابقة تتسامح مع المسافات الزائدة، والهمزات (أ/ا)، والتاء المربوطة (ة/ه)، والياء (ى/ي)، وعلامات مثل `-` و`/`.
- الصنف الموجود بنفس الاسم في أكثر من فرع أو قسم يأخذ نفس الصورة.
- صنف بلا صورة يظهر بمربع فاتح فيه أيقونة، فلا مشكلة في إضافة الصور على دفعات.

## مواصفات الصورة
- أفقية بنسبة 4:3 (مثل 800×600). الصورة تُقص تلقائياً من المنتصف لتملأ المربع.
- الحجم الأقصى 400 KB للصورة، حتى يفتح المنيو بسرعة على باقات الموبايل. الاختبارات ترفض الأكبر.
- صور المطعم الحقيقية فقط.

لتصغير صور كثيرة مرة واحدة (يقصها 4:3 ويحفظها WebP بعرض 800):
```bash
cd app
python3 -I data/tools/prepare_menu_images.py مجلد_الصور_الأصلية menu-images
```

## كيف ترفعها من المتصفح (GitHub)
1. افتح مجلد `app/menu-images` في المستودع على GitHub.
2. اضغط **Add file** ثم **Upload files** واسحب الصور.
3. اضغط **Commit changes**.

الصور تظهر بعد إعادة بناء التطبيق ونشره. اختبار `npm test` يذكر أي صورة اسمها لا يطابق صنفاً.
